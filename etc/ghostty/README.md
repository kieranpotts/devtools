# Ghostty config

Reference:
https://ghostty.org/docs/config/reference

Most settings can be reapplied by running the "Reload Config" command from the menu (`Ctrl+P`).

## Notes

I have enabled [`window-save-state`](https://ghostty.org/docs/config/reference#window-save-state), although this is currently supported only on macOS. Linux support [is pending](https://github.com/ghostty-org/ghostty/discussions/12055) an update to the GTK platform.
